# Vrinda Dashboard – Data Analytics 

## Project Overview

The Vrinda Dashboard – Data Analytics project analyzes retail sales data to understand customer behavior and business performance. Using Microsoft Excel, the project converts raw data into an interactive dashboard that displays key insights such as sales trends, customer demographics, and order status. This dashboard helps in making quick and data-driven business decisions.

---
## Features
- Data cleaning and preprocessing  
- Creation of pivot tables  
- Interactive dashboard with slicers  
- Visualization of key business trends  
- Insights into sales performance
